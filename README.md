# 프론트엔드 포트폴리오 (면접용)

대표 프로젝트를 한 곳에 모아 **각 저장소로 바로 이동시키는** 허브 페이지입니다.
사용 기술과 짧은 설명을 함께 보여주고, 그 이상은 각 프로젝트가 책임집니다.

## 이 페이지가 하는 일 / 하지 않는 일

**한다**

- 대표 프로젝트 5개를 한눈에 보여주기
- 각 프로젝트 저장소로 바로 이동시키기 (모든 카드의 주 동작)
- 전체적으로 어떤 기술을 쓰는지 정리해서 보여주기
- 프로젝트마다 어떤 문제를 풀었는지 짧게 설명하기

**하지 않는다**

- 설치·실행 방법 안내 → 각 프로젝트 저장소 README의 몫
- 경력·학력 등 줄글 이력 → 별도 이력서 문서의 몫
- 프로젝트 화면 스크린샷 → 실제 동작은 각 프로젝트에서 확인

## 구성

정적 3파일 구조입니다. 빌드 도구나 의존성이 없습니다.

- `index.html` — 전체 마크업. 랜딩 + 프로젝트 5개 + 기술 스택 + 설명 모달 5개
- `styles.css` — 전체 스타일. 브레이크포인트는 900px, 620px
- `app.js` — 푸터 연도, 스크롤 등장 효과, 설명 모달 제어(딥링크 포함)

## 로컬 실행

별도 설치 없이 `index.html`을 브라우저에서 열면 됩니다.

## 수록 프로젝트

| # | 프로젝트 | 저장소 | 상태 |
|---|---|---|---|
| 01 | Standard MES | `standard-single-process-mes` | 라이브 데모 |
| 02 | Dayflow | `dayflow` | 라이브 데모 |
| 03 | Standard CMS | `standard-cms` | 기능 정리 중 |
| 04 | Automation Suite | `automation-suite` | 정리 중 |
| 05 | Web IDE (구름톤 팀 프로젝트) | `goorm_team_project` | 아카이브 |

각 카드의 **프로젝트 열기**가 주 동작이고, **간단 설명**을 누르면 모달에서 풀려던 문제와 설계 선택을 볼 수 있습니다.

### 검증 결과

헤드리스 Chrome으로 실제 렌더링을 확인했습니다.

- 1440 / 1024 / 768 / 390px 전부 가로 넘침 없음 (`scrollWidth == viewport`)
- 본문 명암비 최저 4.79 (WCAG AA 기준 4.5 통과)
- 제목 계층 h1 → h2 → h3, 건너뜀 없음

### 미완료

- `og:image` 미설정 (공유 시 미리보기 썸네일 없음) — 실제 화면 캡처 없이 채우지 않음
- 라이브 데모는 Dayflow·MES·CMS만 연결됨 — Automation Suite·Web IDE는 아직 배포 전이라 저장소로 연결
- MES 데모는 4개 프론트(사무·현장·태블릿·대시보드) 중 사무/관리 화면만 카드에 연결. 나머지 3개는 모달에도 아직 안내 없음
- `goorm_team_project`는 저장소에 zip 산출물만 있음 → 소스를 풀어 재정리 필요, 담당 역할 미기재
- Git 커밋 이력 없음 (`main` 브랜치에 커밋 0개)

## 원칙
